# Animations

Drop Mixamo .fbx or .glb files here. They'll be available in the Avatar Lab.

## How to get animations from Mixamo:
1. Go to https://www.mixamo.com
2. Upload any character (or use a Mixamo default)
3. Browse and select an animation
4. Download as FBX (Binary, no skin)
5. Place the .fbx file here
6. Add an entry to ANIMATION_LIBRARY in frontend/src/avatar/animations.ts
