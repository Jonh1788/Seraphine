# Mobile v3 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar as 10 telas do handoff v3, construir o orçamento mensal de custo que duas delas exigem, e fechar duas divergências entre o que o app mostra e o que o sistema faz.

**Architecture:** Telas em `src/mobile/screens/` com CSS e teste próprios, registradas na `registry.ts`, consumindo as camadas de api existentes. Uma única peça compartilhada nova: `MobileSheet`, moldura dos três modais. Backend ganha orçamento mensal em `seraphine/telemetry/` e passa a ser dono único da lista de backends flat.

**Tech Stack:** React 18 + TypeScript + Vite (Tauri 2 webview) · vitest + @testing-library/react · FastAPI + sqlite (backend) · pytest

**Spec:** `docs/superpowers/specs/2026-08-01-mobile-v3-design.md`

## Global Constraints

- **Nada renderiza valor que o dado não sustenta, e nada falha em silêncio.** Vale em toda tela.
- **Um custo exibido errado é pior que um custo ausente.** Duas telas mostram dinheiro.
- Zero emoji em qualquer texto renderizado. Ícones inline de `src/icons/Icons.tsx`.
- Nenhum componente pode `return null`.
- Telas não fazem `fetch` nem tocam `API_BASE`: consomem a camada de api do domínio.
- Tokens, moldura e padrões iOS: os do `handoff_mobile/README.md` original, inalterados.
- Alvo de toque ≥ 44pt em todo controle. **Já existe** a regra compartilhada em `src/mobile/obsidian.css` presa ao `aria-label` — use os mesmos rótulos (`Voltar`) em vez de criar mecanismo novo.
- Versão do app sai de `tauri.conf.json`. O "2.4.0" do mockup é literal, não valor.
- Restrições de ambiente pré-existentes, **não são achados**: `pnpm test` completo trava em `src/App.test.tsx` (WebGL); `pnpm lint` não roda (`@eslint/js` ausente); vitest coleta 5 specs Playwright de `e2e/` como falha. Rode suítes escopadas.
- Commits com pathspec explícito. **Nunca `git commit -a`** — o índice é compartilhado.

## Padrão normativo das tasks de tela

**Esta seção é binding em toda task de tela.** A onda anterior a usou e ~25 reviews a citaram; o que mudou está marcado.

1. **Arquivos próprios**: `screens/<Nome>Screen.tsx` + `<Nome>Screen.css` + `__tests__/<nome>.test.tsx`. Não editar arquivo de outra tela. **Exceção única desta onda:** os três modais consomem `MobileSheet` (Task 4).
2. **Prefixo de classe único** por tela (`ms-<tela>-`), incluindo `@keyframes` — nomes de keyframe são globais.
3. **CSS importado no topo** do `.tsx`.
4. **Três estados, sempre**: dado, vazio e erro. O carregamento é **esqueleto sem texto** (`aria-hidden`), nunca um valor literal.
5. **`role="alert"` numa região só.** O review final da onda anterior encontrou 5 alerts simultâneos numa tela; blocos secundários usam `role="status"`.
6. **Ausência é afirmada.** Um teste que não verifica um elemento não é o mesmo que um que verifica sua ausência.
7. **Mutação obrigatória**: altere a implementação, mostre qual teste cai, reverta. Um teste que passa com a lógica desligada não conta.
8. **Vazio afirma que não é erro** (`queryByRole('alert')` nulo).

async def test_sem_orcamento_o_summary_traz_budget_nulo(service):

    assert s["budget"] is None


@pytest.mark.asyncio
async def test_projecao_usa_gasto_real_do_mes(service):
    await service.set_budget(30.0)
    await service.record(backend="openrouter", model="x/y", cost_usd=11.60)
    s = await service.summary(days=30)
    b = s["budget"]
    assert b["monthly_usd"] == 30.0
    assert b["spent_usd"] == pytest.approx(11.60)
    assert b["days_left"] >= 0
    # projeção = gasto/dia decorrido * dias do mês; nunca negativa
    assert b["projected_usd"] >= b["spent_usd"]


@pytest.mark.asyncio
async def test_orcamento_zero_e_valido_e_diferente_de_ausente(service):
